# 第 121 轮评审（2026-11-01）— 一直在动的背景

这轮回到 R-A（前端美观）。前面几轮查的是"信息对不对"，这轮查"用起来舒不舒服"。

## 1. F-193（P2）32 秒的无限动画，没有尊重系统设置

全局背景是三层径向渐变 + `animation: drift 32s ease-in-out infinite`。
整份样式表里**没有一处** `prefers-reduced-motion`。

这不是审美问题：对前庭功能敏感、偏头痛、注意力障碍的用户，持续移动的大面积背景是实实在在的障碍。
WCAG 2.3.3 明确要求提供关闭方式。

## 2. 修法

    @media (prefers-reduced-motion: reduce) {
      .app-backdrop::before,
      .app-backdrop::after { animation: none; }
    }

并在 check-ui 里加一条静态规则：**样式表里只要出现 animation 声明，就必须出现 prefers-reduced-motion**。

自测（删掉整块）：

    styles/globals.css animates without a prefers-reduced-motion block

## 3. 顺带确认的两件事（都没有缺陷）

| 检查 | 结论 |
|---|---|
| 有没有用 `outline-none` 抹掉键盘焦点 | 全站 0 处，按钮沿用浏览器默认焦点环 |
| 焦点颜色和背景的对比 | `--ring` 与 `--background` 的组合已在对比度检查覆盖范围内 |

第二条尤其值得记：r99 修过"缺令牌就跳过"，所以现在这类检查是真的在跑。
