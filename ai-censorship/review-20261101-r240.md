## 3. 没做成的：日志级别（F-312）

原版节点抽屉能调日志级别。我查了 methodindex，服务在：api.logger.LoggerRpcService，Set=1 / Get=2。
也找到了 upstream 的 proto：

    enum LogLevel { DISABLED=0; ERROR=1; WARNING=2; INFO=3; DEBUG=4; TRACE=5; }
    message SetLoggerConfigRequest { LogLevel level = 1; }
    message GetLoggerConfigResponse { LogLevel level = 1; }

然后撞到墙：internal/pb 里**没有 api.logger 的生成包**，仓库里也没有 protoc 和 proto 源文件；
而 Caller 的签名是 Call(..., req proto.Message)，没有"发原始字节"的口子。

我一度想用 common.UUID（field 1 是 varint）冒充请求体把 level 塞进去——wire 格式确实一样，
但那会让下一个读代码的人以为日志级别和 UUID 有关系。**放弃**，记为 OPEN，写清两条真实路径。
