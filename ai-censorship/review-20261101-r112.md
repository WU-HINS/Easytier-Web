## 2. 一个真实的小坑：重复的 key

copy 表里本来就有 `account` 段（改密码那块用的），我又新加了一个同名段，
TypeScript 先按"对象字面量重复属性"报错：

    src/copy/zh-CN.ts(136,5): error TS1117: An object literal cannot have multiple
    properties with the same name.

合并时还留了一处重复的 `title`，再报一次，才彻底干净。

值得记的是：**这类错误全部由 tsc 在构建时拦住**，没有一个能进到运行时。
这也是"前端也要有门禁"的直接理由——它们本来就会被编译器抓住，前提是有人跑它。
