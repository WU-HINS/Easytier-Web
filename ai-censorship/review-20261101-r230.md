# 第 230 轮评审（2026-11-01）— 全局壳补齐三项，语言切换明确没做

原版侧边栏有：语言切换、文档、封禁设备、改密。我们只缺这四样。

## 1. 做了三项

| 入口 | 实现 |
|---|---|
| 封禁设备 | 新路由 /devices/blocked，复用已有 BlockedDevices 组件 |
| 修改密码 | 新页面 /account/password：当前/新/确认 + 两次一致校验，错误由服务端返回 |
| 文档 | 顶栏外链 https://easytier.cn/ |

## 2. 没做语言切换，以及为什么

文案现在是单一模块 client/src/copy/zh-CN.ts，被约 20 个组件**直接 import**。
要做出真正的语言切换，得先把它抽成 locale 表 + React context，再逐个组件改引用——这是一次结构性重构，
不是一个按钮。硬塞一个只切几个词的开关反而是假的，所以这一项留缺口并写进 UI-MATRIX。
