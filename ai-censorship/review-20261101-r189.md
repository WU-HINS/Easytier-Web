# 第 189 轮评审（2026-11-01）— 乱序：不用真 NAT 也能测

上一轮说"跨 NAT / 乱序"受环境所限。这句话只对 NAT 成立，**乱序不需要 NAT**：
UDP 可以在本机把一帧拆成两片、先发后片再发前片。

## 1. 用例

TestReorderedPiecesOverUDPStillMerge：真实 UDP 监听 + DialUDP，同一事务的两片按 1→0 顺序发送，
断言处理器被调用一次。

## 2. 探针

把重组器改成"按到达顺序存"，也就是不再用 piece_idx：

    handler ran 0 time(s) for a request delivered out of order, want 1

恢复后通过。

## 3. 判断

"环境不允许"这句话，值得每次都追问一遍：不允许的是**整个场景**，还是场景里的某一部分？
NAT 确实做不了；乱序做得了，而我上一轮把它们混成了一条。

至此只剩"地址映射"一项真正受环境限制。
