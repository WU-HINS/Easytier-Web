# 第 68 轮评审（2026-11-01）— 把最后一块界面补上

F-055 从 r22 挂到现在：后端接口齐全，前端没接。契约检查一开始列出 19 条"无客户端调用"的路由，
逐轮补到剩下两条真正的缺口——**网络详情**和**成员覆盖配置**。

## 1. 这两条为什么重要

| 接口 | 没有它会怎样 |
|---|---|
| `GET /networks/{id}` | 界面只能看到列表里的摘要，看不到 peer url / CIDR / 组网方式的完整值，出问题时无法核对 |
| `GET/PUT /networks/{id}/members/{deviceID}/config` | **成员级覆盖配置只能改数据库**——这是唯一一条必须绕开控制台的运维动作 |

第二条尤其不像"缺个按钮"：覆盖配置是排障手段（某个设备网段冲突、需要单独调 MTU 时改它），
而它此前完全不可达。

## 2. 实现

`member-override.tsx`：每行成员一个"高级配置"开关，展开后是 JSON 文本框 +
保存 / 清除。客户端先 `JSON.parse` 校验再提交（服务端还会再校验一次，但没必要让用户看到 400）。

网络详情渲染在成员列表标题下方一行：组网方式 · CIDR · peer urls。
