## 1. 我引入的确定性死锁（F-254，已修）

r162 我把"脏包丢弃"抽成纯函数，然后让 Recv 在遇到哨兵时**递归调用自身**：

    t.readMu.Lock(); defer t.readMu.Unlock()   // 非可重入
    ... if errors.Is(err, errSkipDatagram) { return t.Recv(ctx) }   // 再次 Lock → 自锁

任意 4 字节脏数据报即可让客户端读路径永久挂住。已改为 for 循环 + continue。

**而它之所以没被发现，恰恰因为我把规则抽成了纯函数**：用例测的是纯函数，从不穿过 Recv。
抽函数提高了可测性，同时把调用点的正确性移出了测试面。
