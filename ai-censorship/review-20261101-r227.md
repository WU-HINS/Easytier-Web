# 第 227 轮评审（2026-11-01）— 设备接入引导、搜索与实例数

原版设备页有三样我们没有：接入引导（enroll 命令 + 复制）、搜索、实例数。

## 1. 接入引导要先补后端

前端拼不出正确命令，因为 console-info 只回协议和用户名，**没有控制面端口**。
于是先让 webd 从 --config-server 地址解析端口传进 httpapi.Config，再在 console-info 里返回。
命令由前端按 console-info 现拼：

    easytier-core --config-server tcp://127.0.0.1:28202/root-owner

带复制按钮。这样换端口、换账号，命令自动跟着变，不会写死。

## 2. 列表增强

- 搜索：名称 / 别名 / machine id，忽略大小写；命中数显示在右上角；无匹配显示「没有匹配的设备」；
- 实例数列：直接取 running_network_instances 的长度。

## 4. 必须记下来的一个测试 bug（F-297）

我的验收脚本用 replace(/\s+/g, " ") 归一化文本。但模板把 \s 吞成了 s，正则变成 /s+/g——
**把文本里所有字母 s 换成空格**。于是 "easytier" 显示成 "ea ytier"、"ops, audit" 显示成 "op , audit"。
前几轮我以为是 DOM 或字体问题，其实是自己的脚本在改文本。改用 split/join 后一切正常。

教训：断言文本前先确认"归一化"没有改变内容；宁可逐单元格取 textContent。
