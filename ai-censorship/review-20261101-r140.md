## 2. R-F 找到一条"守卫结构上看不见"的泄露

F-202 声称"28 处统一脱敏 + 规则挡住新增"。实际还有 3 处写成：

    status := http.StatusInternalServerError
    if errors.Is(err, bal.ErrNotFound) { status = http.StatusNotFound }
    writeError(w, status, err.Error())

守卫按 StatusInternalServerError 字面量取行，status 是变量 → **结构上看不见**。
现在三处改成 404 分支 + 固定文案，守卫也加了一条：writeError 的 status 参数必须是字面量。
