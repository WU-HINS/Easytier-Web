# 第 184 轮评审（2026-11-01）— 补边界值，让 off-by-one 无处可藏

F-256：udp_parse_test 只有"明显越界"的样本（MTU+1、PeerHeader-1），把比较符写成 >= 不会红。

## 1. 新增四条边界断言

| 断言 | 拦住的变异 |
|---|---|
| 恰好少一字节 → 必须跳过 | 4+bodyLen > read 写成 >= |
| 恰好足长 → 必须接受 | 同上，反向 |
| 空 body → 必须跳过 | bodyLen < PeerHeaderSize 被放宽 |
| bodyLen 恰为 UDPMTUBytes → 必须通过长度检查 | > 写成 >= |

## 2. 探针

把 > UDPMTUBytes 改成 >=：

    a body of exactly UDPMTUBytes was rejected by the length check

恢复后通过。

## 3. 判断

R-D 的原话是"越界样本谁都会写，边界才是变异存活的地方"。这一轮把它补上，
而且每条断言都指名它能拦住哪种变异——这样以后有人放宽比较符，红的那一刻就知道是哪一条在起作用。
