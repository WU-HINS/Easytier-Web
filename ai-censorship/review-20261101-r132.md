# 第 132 轮评审（2026-11-01）— 名单里写着两份文件，遍历从没走到过它们

r131 的教训是"检查器自己会漏"。这轮把同样的怀疑带到 design-tokens 检查器上，
结果发现的不是规则过宽，而是**名单是死的**。

## 1. F-206（P2）skip 名单保护着两个从未被扫描的文件

    const skip = new Set(["ui/tokens.css", "styles/globals.css"]);
    ...
    else if (full.endsWith(".tsx") || full.endsWith(".ts")) out.push(full);

遍历只收 `.ts/.tsx`，而 skip 名单里是两份 `.css`。
也就是说：**这份名单从来没有生效过，因为那两份文件根本不会被访问**。
样式表里的颜色和尺寸完全在检查之外。

## 2. 把它们纳进来，立刻暴露 4 处写死值

| 位置 | 原值 | 改为 |
|---|---|---|
| 焦点环 | `2px` | `--focus-ring-width: calc(var(--u-3)/4)` |
| 边框 | `1px solid` | `var(--hairline) solid` |
| 网格线 | `1px` | `var(--hairline)` |
| 面板阴影 | 四段裸 px 偏移 | `--shadow-panel` |

阴影那一条值得一提：偏移量本身就是设计决定，跟着令牌走才能让深浅两套主题一致。

## 3. 只放行三类 CSS 写法

| 放行 | 理由 |
|---|---|
| 以 `--` 开头的行 | 令牌定义就该写在这里 |
| `@media` 断点 | CSS 变量不能出现在媒体查询里 |
| `grid-template-columns` | φ 分割的唯一真源 |

其余一律按字面量处理。自测：在 `globals.css` 里加一行 `color: #ff0000`：

    styles/globals.css:103  hex colour  #ff0000

## 4. 扫描面变化

34 个文件 → **36 个文件**（多了两份样式表）。

## 5. 台账

206 项：196 FIXED / 7 ACCEPTED / 3 MONITOR / 0 OPEN。

## 6. 判断

一条从未生效的规则，比一条宽松的规则更危险：它让人以为"这里已经看住了"。
r92 的 fetch 收敛点、r131 的整行豁免、r132 的死名单——三次都是同一件事：
**守卫的价值等于它实际看过的文件数，等于 0 时价值也是 0。**
