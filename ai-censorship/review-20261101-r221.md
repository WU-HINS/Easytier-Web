# 第 221 轮评审（2026-11-01）— 网络改成单独子页面，与原版对齐

原版（`frontend/src/main.ts`）里网络详情是独立路由 `networks/:networkId`，带 members / acl / credentials / settings 页签。
我们之前把它做成列表内的内联展开——方向反了。

## 1. 改动

| 位置 | 之前 | 现在 |
|---|---|---|
| 列表页 | 点「成员」就地展开两个面板 | 纯列表，每行一个「管理」链接 |
| 详情 | 无独立路由 | `/networks/{id}`：页头 +「成员」「设置」页签 |
| 刷新 | 选中状态丢失 | 直接可打开 |

## 2. 顺手处理的耦合

成员面板原来强制要求一个 `onClose`（用于收起）。放进页签后没有"收起"这个概念了，
于是把回调改成可选，并让「返回」按钮在无人接管时**不渲染**——避免出现一个点了没反应的按钮。

## 3. 浏览器实测（Playwright）

- `detailUrl` → `/networks/6d16bcb9-…`
- 列表出现「管理」链接
- 成员页签出现 `edge-hk-01`
- 设置页签出现「高级设置」
- **刷新详情地址后仍可打开**
- `problems: []`（0 console error、0 失败请求）

## 4. 判断

这一轮没有新功能，是把信息架构调回原来的样子。
值得记的是：页面拆成路由之后，"能不能刷新"这类问题才会暴露出来——内联展开时它根本不存在。
