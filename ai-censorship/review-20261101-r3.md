## 1. R-E 渗透 / R-F 越权：F-004 闭环

**问题回顾**：配额只在控制台下发路径判定；设备自己起第 N+1 个实例，控制台只能计数，不能收敛。

**本轮实现**（`internal/central/quota.go`）：

1. `session.Manager.OnlineInstances(userID)` 汇总在线会话上报的实例（按机器分组）。
2. `Reconciler.EnforceQuota`：超过配额时按 `(machine, instance)` 排序，保留前 N 个，
   对每台超限设备下发 **`RetainNetworkInstance`**（api.manage.WebClientService#3）。
3. 守护进程每 5 秒随心跳扫描一起执行；配额为 0 视为不限制。
4. 保留集合是**确定性**的，因此重复下发幂等，不会来回抖动。

**回归** `TestQuotaEnforcedOnHeartbeatPath`：

```
设备上报 3 个实例（...003 / ...001 / ...002），配额 2
→ 控制台下发 RetainNetworkInstance，携带 [...001, ...002]
→ report.Trimmed = 1, report.Failed = 0
配额 5（未超）→ 不下发；配额 0（不限制）→ 不下发
```

**残余（P2，F-016）**：两轮扫描重叠时可能重复下发同一 Retain。内容幂等，接受。
