# 第 251 轮评审（2026-11-01）— 英文补到 100%，并让"缺键"变成红灯

之前英文只覆盖外壳/导航/概览/登录。切到英文，一半页面还是中文——这比全中文更糟，因为读者会以为翻译坏了。

## 1. 做了什么

| 项 | 内容 |
|---|---|
| 接线 | 28 个组件全部改成 `useCopy()`；把 `network-advanced` 的开关表与 `appearance` 的主题表从模块级移进组件体（模块级常量没法响应语言切换） |
| 文案 | 英文表补到 **337/337 键（100%）** |
| 守卫 | 新增 `scripts/check-i18n.mjs`，接进 gate 与 CI：中文表里少一个英文键就失败 |
| 断言 | ui-tour 增加「设备页也是英文」——切到英文后搜索框必须是 Search devices |

## 2. 三次自伤（都由 tsc 兜住）

1. 用正则给每个导出组件插入 hook，正则里的反斜杠被外层模板吃掉，匹配到 0 个文件；
2. 改成行扫描后，把 hook 插进了多行参数列表中间（MemberEditor 的签名里），语法直接坏掉；
3. 同一个脚本还往 LocaleProvider 自己身上插了 useCopy()——provider 不能用自己的 hook。

三次都是 tsc 立刻报错。**"正则改代码"这件事，先跑 tsc 再谈对不对。**

## 3. 结果

14 个分区全部 100%，337/337 键有英文。
空库跑 ui-tour：**26 条全绿**，其中「device page is translated too (Search devices)」。
