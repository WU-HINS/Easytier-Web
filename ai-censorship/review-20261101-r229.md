# 第 229 轮评审（2026-11-01）— 网络创建向导

原版创建网络时能选组网方式（standalone/manual/gateway/public server）、安全模式、初始节点。
我们的表单只有名称与网段，方法写死 Standalone——等于放弃了三种组网方式。

## 1. 改动

- createNetwork 从 (name, cidr) 改成接收完整 settings 对象；
- 表单加：组网方式 select、Manual 时的节点地址（每行一个）、Gateway/PublicServer 时的公共服务器地址、安全模式。

## 2. 浏览器实测

| 断言 | 结果 |
|---|---|
| 四种方法都在下拉里 | 通过 |
| 默认（Standalone）不显示节点地址 | 通过（0 个） |
| 选 Manual 后出现节点地址 | 通过（1 个） |
| 创建后出现在列表 | 通过（wizard-net） |
| 服务端存的是 Manual + peer_urls | 通过 |
| console error / 失败请求 | 0 |

服务端返回：networking_method=Manual、peer_urls=["tcp://127.0.0.1:21010"]、virtual_cidr=10.190.0.0/29。
