## 5. 判断

对比度检查存在了很多轮，一直是"通过"的。它不是错的，只是**看得太少**。
一条规则的价值 = 它看过的东西 × 它断言的东西；两者都可以是 0。

## 6. 门禁期间 PostgreSQL 挂了（F-209）

跑本轮门禁时，本机的 PostgreSQL 实例意外停机。门禁的报错是：

    FAIL  postgres api
    dial tcp 127.0.0.1:55432: connect: connection refused

**基础设施故障和代码失败长得一模一样。** 我先花时间怀疑 r128 改的播种逻辑，
再用 `ps` 才确认数据库进程根本没在跑。

修法：postgres 三步之前加可达性预检（`pg_isready`，没有就 python 试连），
不可达时只吐一行：

    == postgres steps   FAIL (database not reachable; check EASYTIER_TEST_PG_DSN)

用 59999 端口的假 DSN 验证过，输出的正是这一行；数据库恢复后完整门禁通过。

顺带把实例拉起来了（`pg_ctl -D /tmp/pgtest/data -p 55432`，数据目录属主是 `pgtest`，
残留的 `postmaster.pid` 要先删）。
