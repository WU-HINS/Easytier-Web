# 第 172 轮评审（2026-11-01）— 三条里最后一条是可测的

剩下三条：F-096（清除 OIDC state cookie 时缺属性）、F-063（明文凭据的界面语义）、F-251（readMu）。
这轮只查证，不动代码。

## 1. F-096 是可测的，而且确实没有守卫

grep 结果：

| 位置 | 断言的粒度 |
|---|---|
| tls_test.go:73 | 把 Set-Cookie 拼起来看整体，只证明"有这个头" |
| oidc_bind_test.go:115/153 | 只做行为断言（篡改 state 被拒） |

**没有任何用例断言 Secure / SameSite / HttpOnly 这三个属性。**
而 F-096 修的正是"清除分支缺少与设置分支一致的属性"——
一个缺 Secure 的清除 cookie，在明文链路下可能被中间人抢先消费。

## 2. F-063 与 F-251 的性质不同

- F-063 是**界面语义**（"只显示这一次"的文案与清空时机），要断言它需要前端测试运行器，当前没有；
- F-251 是**并发读**，connected socket 无法从外部注入第二个读者，与 F-252 同因。

这两条的诚实结论是"当前测试面覆盖不到"，而不是"已覆盖"。

## 3. 判断

三条都查清了性质：一条可测且有价值（F-096），两条需要一个当前不存在的测试面。
