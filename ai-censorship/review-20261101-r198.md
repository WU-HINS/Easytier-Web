## 1. 面板内容

| 字段 | 说明 |
|---|---|
| MTU | 留空表示不设置 |
| 实例接收限速 | bps，留空表示不限 |
| 监听地址 | 逗号分隔，写入 listener_urls |
| 白名单 | machine id 或 *，逗号分隔 |
| 功能开关 | 不建网卡 / 禁用 P2P / 禁用 IPv6 / 多线程 |

读取：把 JSON 反序列化回字段；保存：只写非空字段，整段替换。
错误用 role=alert，成功用 role=status（与项目里其它表单保持一致）。
