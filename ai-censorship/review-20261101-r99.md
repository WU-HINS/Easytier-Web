# 第 99 轮评审（2026-11-01）— "缺了就跳过"也是一种放过

前几轮都在冒烟脚本上找"记录 ≠ 断言"。这轮回到前端（R-A），
看设计令牌与对比度这一块还有没有同类的宽松判断。

## 1. F-167（P2）对比度检查会静默跳过缺失的令牌

检查器对每个主题跑五组配色。原来缺令牌时打印 `SKIP (token missing)` 并继续：

    if (!tokens[fg] || !tokens[bg]) {
      console.log(... + " SKIP (token missing)");
      continue;
    }

实测：把 `.dark` 里的 `--muted-foreground` 整行删掉——
深色主题的"次要文字"与"次要文字在底色上"两条检查**直接消失**，检查器仍然输出

    all contrast checks passed

这不是"这条不适用"，而是"模板不再有这种颜色"：深色下文字会退回继承值，是实打实的缺陷。

## 2. 修法

SKIP 改成 MISSING 并计入失败：

    secondary text               MISSING (token not defined in this theme)
    secondary text on muted      MISSING (token not defined in this theme)

恢复令牌后全绿。审计新增第 14 条变异（删深色令牌）把它固定住，现为 14/14。

## 3. 顺带确认：深浅两套都在检查

原本担心"只检查了浅色"，读代码后确认两套都跑（`[':root','light'], ['.dark','dark']`）。
**这一条没有缺陷，记下来是因为"我猜有一个问题"和"确认没有这个问题"都需要证据。**
