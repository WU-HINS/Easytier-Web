# 第 223 轮评审（2026-11-01）— 设备也做成子页面

网络改成子页面之后，设备列表还留着「点按钮就地展开路由」的老写法。原版是 deviceList/device/:deviceId 的嵌套路由。这一轮把设备也拆出去，并把「这台设备在哪些网络里」补上——之前界面上根本看不到。

## 1. 页面结构

| 区块 | 内容 |
|---|---|
| 页头 | 名称 / machine id / 在线徽标 / 版本 / 接入地址 / 最后在线 |
| 所属网络 | 网络显示名、网络名、虚拟 IP、运行中标记、「打开网络」链接 |

数据来源：GET /api/v1/machines 给页头，GET /api/v1/networks/{id}/members 逐个网络取成员再按 device_id 过滤。

## 2. 浏览器实测（Playwright）

- 「所属网络」出现 生产网 与虚拟 IP 10.180.0.1
- 刷新详情地址后仍可打开
- problems: []（0 console error、0 失败请求）

## 3. 过程中的代价

这一轮在写文件上反复栽跟头：模板字符串把换行符和转义序列吃掉，三次写坏 TSX（其中一次把 http.ts 的 networkMembers 重复定义）。最后改成「分块追加 + 行号定位」才稳定。真正的时间花在这里，不是花在页面上。
