## 1. F-120（P2）环境变量文档只覆盖五分之一

代码里读取的 `EASYTIER_*` 有 20 个，README 只提到 4 个（`DB_DRIVER`、`DB_DSN`、
`OIDC_ISSUER`、`TEST_PG_DSN`）。漏掉的是真正会影响行为的：

| 漏掉的 | 影响 |
|---|---|
| `EASYTIER_LOG_LEVEL` | 出问题时调不出 debug 日志 |
| `EASYTIER_DB_MAX_OPEN / MAX_IDLE / CONN_LIFETIME` | PostgreSQL 连接池调优 |
| `EASYTIER_DB_AUTO_ALIGN / ALIGN_DRYRUN` | 预演升级 |
| `EASYTIER_DB_BACKUP / BACKUP_DIR / BACKUP_CMD` | 快照开关与位置（r53 刚验证过的路径） |
| `EASYTIER_OIDC_*`（7 个） | **首次引导**：没有管理员能登录界面时，只能靠环境变量配 OIDC |

最后一条尤其要紧：全新部署、还没初始化时，环境变量是配置 OIDC 的**唯一**通道。
