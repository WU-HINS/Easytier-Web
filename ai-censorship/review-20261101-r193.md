# 第 193 轮评审（2026-11-01）— 三通道真的同时接上，只推了一条

上一轮只有会话层用例（三条隧道并存 + ByMachine 选路）。这一轮把它推到端到端。

## 1. 用例

TestOneDeviceOnThreeTransportsGetsOnePush：

1. 起三个**真实**监听器：wire.ListenTCP / ListenWS / ListenUDP；
2. 三个客户端各自 Dial 并跑 rpc.Mux，各自注册 RunNetworkInstance 计数器；
3. 同一个 machine 三次心跳（分别走 tcp / ws / udp）；
4. 建网 + 加成员 + 跑一次 ReconcileUser；
5. 断言：总推送数 == 1，且落在 tcp；ws 与 udp 收到 0。

## 2. 探针

把传输从会话键里去掉（回到 (用户, 机器)）：

    tcp received 0 push(es), want 1 (it is the preferred transport)

注意这条探针的细节：总推送数可能仍是 1（只是推给了 udp），
所以"只推一条"和"推给 tcp"必须分别断言——只断言总数是抓不到这个回归的。
