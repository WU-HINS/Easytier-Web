# 第 224 轮评审（2026-11-01）— 网络列表的搜索与排序

原版 NetworkList 有三件事我们没有：输入即过滤、按显示名排序、显示「N 项」并在无结果时给「清空搜索」。

## 1. 实现

三处都是页面本地状态，不新增接口：过滤按 display_name / network_name 忽略大小写包含；
排序用 display_name 的 localeCompare；计数与空态跟着过滤结果走。

## 2. 浏览器实测（Playwright）

| 断言 | 结果 |
|---|---|
| 输入 alpha 后只剩 1 条 | 通过 |
| 输入不存在时出现「没有匹配的网络」 | 通过 |
| 点「清空搜索」恢复 3 条 | 通过 |
| 计数显示「3 项」 | 通过 |
| 顺序与浏览器 localeCompare 一致 | 通过 |
| console error / 失败请求 | 0 |

## 3. 一次误报

第一次跑断言时 sorted=false——因为我在 Node 里用默认 locale 的 localeCompare 复算，
和浏览器 zh-CN 的 collation 规则不同。改成在页面内让浏览器自己排序再比较，结果一致。
这是测试写法的问题，不是排序没做。
