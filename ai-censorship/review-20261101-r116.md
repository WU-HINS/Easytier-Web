# 第 116 轮评审（2026-11-01）— 三份没人读的文档

完整门禁 20 项全绿（含上一轮的深检记录改动）。然后给"文档"这件事补最后一条规则。

## 1. F-183（P2）docs/ 里有三份孤儿

新增的规则很朴素：**docs/ 下每个 .md 都必须被 root.md 引用**。
一加上就报出三份：

| 文档 | 状态 |
|---|---|
| docs/PROTOCOL.md | 只有 README 提到 |
| docs/DESIGN.md | 只有 README 提到 |
| docs/REWRITE-PLAN.md | 只有 README 提到 |

它们从早期就存在，而 root.md 自称"规范唯一入口"——**入口里没有它们**。
没人链接的文档等于没人读，而没人读的文档会安静地过期。

## 2. 修法

root.md §5.10 的文档表补三行，并写明各自的校验方式：

| 文档 | 校验 |
|---|---|
| PROTOCOL.md | `check-wire` 校验编码，文档正文靠评审复查 |
| DESIGN.md | `check-contrast` / `check-design-tokens` |
| REWRITE-PLAN.md | 人工核对（待办见 §8） |

第三行是诚实的：它没有机器校验，写清楚比假装有更有用。

## 3. 自测

新建 `docs/TEMP-ORPHAN.md`：

    docs/TEMP-ORPHAN.md is not referenced from root.md

删掉后转绿。规则还要求 docs/ 至少 5 个文件，防止目录被清空时检查静默通过。

## 4. 三条文档规则合起来

| 规则 | 防什么 |
|---|---|
| 门禁项必须在 root.md 出现 | 门禁加了、规范没写 |
| 引用的测试名必须存在 | 文档写了不存在的用例（r85） |
| docs/ 每个文件必须被 root.md 引用 | 文档写了没人读（本轮） |

## 6. 判断

文档体系现在三条腿都站住了：**写了的要存在、存在的要被引用、引用的要对得上门禁**。
这三条都不是靠自律，而是靠 check-docs 每次跑一遍。
