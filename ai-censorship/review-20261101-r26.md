# 第 26 轮评审（2026-11-01）— 网络设置面收口

r25 的结论是"继续补网络编辑面"。本轮把最后一块主体做完：改名、ACL 策略、接入凭据。

## 1. F-062（P2）三块后端能力终于有了入口

| 能力 | 界面 | 说明 |
|---|---|---|
| `PATCH /networks/{id}` | 改名输入框 + 保存 | 只发改动字段，空名被服务端拒绝并把原因显示回来 |
| `GET/PUT /networks/{id}/acl-policy` | JSON 文本框 + 保存 | 文本原样提交，**校验在服务端**；保存成功显示"已保存"，失败显示解析错误 |
| `GET/POST/DELETE /networks/{id}/credentials` | 列表 + 签发 + 吊销 | 密钥只在签发响应里出现一次 |

ACL 刻意做成"原文编辑"而不是可视化规则编辑器：策略语言属于 agent，
做半吊子的可视化只会制造"界面允许但后端编译不过"的组合。

## 2. F-063（P2）凭据密钥的展示约束

密钥不可回看（服务端只存 hash/原文但列表接口不返回）。界面在展示处注明"只显示这一次"，
并且在吊销或再次签发时**清空上一次的明文**，避免明文长期停留在页面上。
