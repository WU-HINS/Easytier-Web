## 2. 发现并修复：F-022 门禁清单与实际执行漂移（P2）

**问题**：r6 新增了 `scripts/check-contrast.mjs`，但章程 `docs/REVIEW-TEAM.md` 的门禁清单**没有同步**——
它仍然是 r2 时代的四条命令。章程声称"任何一条红即不通过"，但少列一项就等于少一道闸。
同时，门禁分散在 5 条命令里，靠人记忆执行，天然会漂。

**修复**：新增 `scripts/gate.sh` 作为**唯一入口**，按顺序执行 7 项并逐项 PASS/FAIL：

```
== backend build        PASS
== backend vet          PASS
== backend tests        PASS
== client build         PASS
== design contrast      PASS
== deploy smoke         PASS
== postgres tests       PASS            (设置 EASYTIER_TEST_PG_DSN 时才跑，否则显式 SKIP)

result: PASS
```

章程与 README 都改为指向该脚本，并写明规则：**新增门禁项必须同时更新章程表格与 gate.sh**——
把"防漂移"写进流程本身。
