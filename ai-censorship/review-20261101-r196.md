# 第 196 轮评审（2026-11-01）— 网络白名单：命中即并网，且只并一次

(B) 最后一项：白名单。它不是配置字段，而是**准入规则**——所以放在对账路径上，而不是编译路径上。

## 1. 实现

| 位置 | 内容 |
|---|---|
| advanced.whitelist | 精确 machine id，或 "*" |
| central.WhitelistAllows | 解析并判断命中 |
| Reconciler.ReconcileUser | 对账前先补齐白名单成员，Report.Enrolled 记录本次加入数 |

## 2. 用例（四个断言）

TestWhitelistedDeviceJoinsByItself：

1. 命中的设备被加入 net-open；
2. 同一设备**没有**被加入白名单不含它的 net-closed；
3. 名单外的设备不会被加入；
4. 第二次对账 Enrolled=0，成员仍为 1（不重复加入）。

探针：让 WhitelistAllows 恒真 → 用例失败（net-closed 里出现了成员）。

## 3. 一条必须写下来的语义

如果管理员移除一个**仍在白名单内**的成员，下次对账会把它加回来。
这不是 bug，是"自动并网"的固有代价，已写进账本条目：**要永久移除，必须同时把设备移出白名单**。
不写清楚的话，这会是将来最难解释的一种"删不掉"。
